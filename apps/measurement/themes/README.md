# Themes

The color themes of [GPUI Kit](https://github.com/longbridge/gpui-kit/tree/v0.9.0/themes),
copied unchanged from v0.9.0. They are licensed under the Apache License 2.0 by Longbridge; each
file names the author and source of its color scheme.

The app bundles them, since the published crates only contain the default light and dark theme.
